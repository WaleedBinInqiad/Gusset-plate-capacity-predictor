# Gusset Plate Capacity Predictor

A CatBoost-based compressive capacity predictor for bolted gusset plate
connections, with a SHAP-style feature-contribution waterfall chart.
Runs entirely in the browser -- no backend, no server, no data leaves the
device. Installable as an Android/iOS/desktop PWA.

## Live files (deploy these as-is)

- `index.html` -- the app itself
- `model_data.js` -- the trained model + precomputed SHAP lookup table (generated by `training/export_for_webapp.py`)
- `manifest.json`, `sw.js` -- PWA manifest + service worker (installability, offline caching)
- `icon-192.png`, `icon-512.png` -- app icons

## Retraining on your own data

The `training/` folder has the two scripts used to produce `model_data.js`:

1. `training/gusset_catboost_tuning.py` -- loads `Gusset.csv`, applies the
   documented bolted-only / non-buckling-cluster filters, tunes a
   CatBoostRegressor via RandomizedSearchCV, saves the model.
2. `training/export_for_webapp.py` -- loads the saved model, exports the
   tree structure for exact in-browser inference, and precomputes real
   SHAP values across a sample of the input space for the explanation
   chart. Writes `model_data.js`.

Run both, then copy the freshly generated `model_data.js` over the one in
this repo root.

## Deploying to GitHub Pages (free hosting, gives a real installable URL)

1. Create a new GitHub repository (public, so Pages can serve it for free).
2. Upload these 6 files to the repository root: `index.html`,
   `model_data.js`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`.
   - Easiest way with no command line: on the repo page, click
     **Add file -> Upload files**, drag all 6 files in, commit.
3. Go to the repo's **Settings -> Pages**. Under "Build and deployment",
   set Source to **Deploy from a branch**, branch = `main`, folder = `/`
   (root). Save.
4. Wait ~1 minute, then GitHub shows the live URL, typically:
   `https://<your-username>.github.io/<repo-name>/`
5. Open that URL on an Android phone in Chrome, tap the menu (⋮), choose
   **Install app** (or **Add to Home screen**). It installs as a
   standalone app with its own icon -- no browser address bar, works
   offline after the first load.

Command-line alternative to step 2, if you have git installed:

```bash
git init
git add index.html model_data.js manifest.json sw.js icon-192.png icon-512.png README.md training/
git commit -m "Initial commit: Gusset Plate Capacity Predictor"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

Then do step 3/4 above (enabling Pages) in the repo's Settings.

## How it works

- **Prediction**: CatBoost's default trees are oblivious/symmetric -- each
  tree is just a sequence of binary feature comparisons with a lookup into
  a table of leaf values. `index.html` reimplements that exactly in
  JavaScript, so predictions match Python's `model.predict()` bit-for-bit.
- **Explanation**: rather than reimplementing TreeSHAP in JavaScript
  (which was tried and found to introduce small errors in per-feature
  attribution), the app instead bundles ~4,000 *real* SHAP values computed
  in Python across the realistic input range, and finds the nearest
  precomputed cases to interpolate an explanation for your specific input.
  The predicted number is exact; the feature-contribution breakdown is an
  interpolated approximation of genuine SHAP output, and the app says so
  in its caption.
